# 任务管理系统

一个基于控制台的 Python 待办任务管理程序。采用面向对象设计，将每条任务抽象为一个类，支持任务增删改查、搜索筛选、统计、数据持久化、HTML 报告导出，以及 OpenCV 生成任务统计图的附加功能。

---

## 一、项目简介

本项目是 Python 课程大作业，模拟日常任务管理场景。用户通过控制台菜单进行操作，实现任务的全生命周期管理。程序启动时自动读取上次保存的数据，退出时自动保存，重新打开数据不丢失。

**技术要点：**
- 面向对象：将一条任务抽象为 `Task` 类，属性封装在类中，行为写成方法
- 文件读写：使用 `|` 分隔字段存储到文本文件
- 字符串处理：日期格式校验、逾期判断（字符串直接比较大小）
- 异常处理：输入非法字符不崩溃，循环重问
- Git 版本管理：多人协作开发，PR 合并到 main 分支

1. **环境要求：**
   - Python 3.8 及以上版本
   - 仅附加任务需要第三方库：`opencv-python`、`numpy`

2. **依赖安装：**
```

pip install opencv-python numpy

```

3. **启动方式：**
- PyCharm 直接运行 `main.py`

## 五、数据格式

每条任务一行，字段用 `|` 分隔，存储在 `tasks.txt`：

```

1 | 买牛奶 | 高 | 2026-10-10 | 未完成
2 | 写报告 | 中 | 2026-10-11 | 已完成

```

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 编号 | 整数 | 删除后自动重新编号 | 1、2、3... |
| 标题 | 字符串 | 不能为空 | 买牛奶 |
| 优先级 | 字符串 | 高 / 中 / 低 | 高 |
| 截止日期 | 字符串 | YYYY-MM-DD 格式 | 2026-10-10 |
| 状态 | 字符串 | 未完成 / 已完成 | 未完成 |

> 日期统一用 `YYYY-MM-DD` 格式，这样比较日期早晚直接比字符串大小即可。

## 七、核心技术难点

| 技术点 | 在哪个功能里 | 怎么讲解 |
|--------|------------|---------|
| Task 类封装 | 整个程序 | `__init__` 初始化属性，`mark_done()` 改状态，`show_info()` 打印信息 |
| 文件读写 | 保存/读取 | `with open()` 自动关文件，`encoding="utf-8"` 防中文乱码，`try/except` 防第一次运行没文件 |
| 日期校验 | 添加任务 | `datetime.strptime()` 尝试解析日期，假日期（如13月32号）会抛 ValueError |
| 逾期判断 | 搜索筛选/导出报告 | 日期统一 `YYYY-MM-DD` 格式，字符串直接比大小就能判断早晚 |
| 删除后重新编号 | 删除任务 | `for j in range(len(tasks)): tasks[j].id = j + 1`，遍历补齐编号 |
| 二次确认循环 | 删除任务 | `while True` 循环，输入别的就提示重问，只有 y/n 才退出 |
| 列表推导式 | 搜索筛选 | `[task for task in tasks if task.status == "未完成"]` 一行筛选 |
| lambda 排序 | 搜索筛选 | `sorted(tasks, key=lambda x: priority_order[x.priority], reverse=True)` |
| HTML 拼接 | 导出报告 | `html_lines.append()` 逐行拼，最后 `"\n".join()` 写入文件 |
| 进度条/标红 | 导出报告 | CSS `width` 百分比做进度条，`color:red` 给逾期任务标红 |
| 空列表除零保护 | 导出报告 | 先判断 `if total == 0: return`，防止完成率除以0崩溃 |

## 八、AI 使用说明

**AI 辅助部分：**
- 类的结构设计（Task 类属性和方法的划分）
- 文件读写代码模板（`with open` 的写法）
- HTML 报告生成（CSS 进度条、表格、逾期标红的写法）
- 报错排查（缩进错误、字段名不一致、除零错误等）

**自己手写/修改部分：**
- 整合各组员代码，统一字段名（deadline）
- 删除功能二次确认改成循环重问，而不是一次就退出
- 退出时自动调用 `save_data()`，不用手动选保存
- 空列表保护（导出报告时 `total==0` 提前 return）
- 所有 input 加 `.strip()`，防止空格导致匹配失败

**每个模块负责人都能讲清自己负责的代码逻辑。**

## 九、遇到的问题与解决

| 问题 | 解决方法 |
|------|---------|
| 输入非法字符后直接返回主界面，操作中断 | 用 `while True` 循环，输入错误时重问，不退出功能 |
| 每次运行都要重新添加任务 | 退出时自动写入 `tasks.txt`，启动时自动读取 |
| 删除任务后编号不连续 | 删除后遍历列表重新编号，保证编号连续 |
| 空列表导出报告除以0崩溃 | 先判断 `if total == 0: return` 提前退出 |
