# 任务管理系统

一个基于控制台的 Python 待办任务管理程序。采用面向对象设计，将每条任务抽象为一个类，支持任务增删改查、搜索筛选、数据持久化和 HTML 报告导出。

---

## 项目简介

本项目是 Python 课程大作业，模拟日常任务管理场景。用户通过控制台菜单进行操作，实现任务的全生命周期管理。程序启动时自动读取上次保存的数据，退出时自动保存，重新打开数据不丢失。

**技术要点：**
- 面向对象：将一条任务抽象为 `Task` 类，属性封装在类中，行为写成方法
- 文件读写：使用 `|` 分隔字段存储到文本文件
- 字符串处理：日期格式校验、逾期判断（字符串直接比较大小）
- 异常处理：输入非法字符不崩溃，循环重问
- Git 版本管理：多人协作开发，PR 合并到 main 分支

## 数据格式

每条任务一行，字段用 `|` 分隔，存储在 `tasks.txt`：

```

1 | 买牛奶 | 高 | 2026-10-10 | 未完成
2 | 写报告 | 中 | 2026-10-11 | 已完成

```

| 字段 | 说明 | 示例 |
|------|------|------|
| 编号 | 删除后自动重新编号 | 1、2、3... |
| 标题 | 不能为空 | 买牛奶 |
| 优先级 | 高 / 中 / 低 | 高 |
| 截止日期 | YYYY-MM-DD 格式 | 2026-10-10 |
| 状态 | 未完成 / 已完成 | 未完成 |

> 日期统一用 `YYYY-MM-DD` 格式，直接比字符串大小就能判断日期早晚。

## AI 使用说明

**AI 辅助部分：** 类结构设计、文件读写代码模板、HTML 报告生成写法、报错排查与调试指导。

**自己手写/修改部分：**
- 整合各组员代码，统一字段名和数据结构
- 删除任务改为循环确认，输入错误不退出当前功能
- 退出时自动保存数据，无需手动选择保存
- 导出报告增加空列表保护，防止除以0报错
- 所有输入添加 `.strip()` 处理，防止空格导致匹配失败

每位成员都能独立讲解自己负责模块的代码逻辑。

## 遇到的问题与解决

| 问题 | 解决方法 |
|------|---------|
| 输入字母或特殊符号时程序崩溃 | 用 `while True` 循环，输入错误时重问，不退出功能 |
| 每次运行任务数据全没了 | 退出时自动写入 `tasks.txt`，启动时自动读取 |
| 删除任务后编号断号 | 删除后遍历列表重新编号，保证连续 |
| 空列表导出报告除以0报错 | 先判断 `if total == 0: return` 提前退出 |
| 输入"13月32号"也能通过 | 用 `datetime.strptime()` 真正解析日期，假日期抛异常 |
| 第一次运行没文件直接报错 | `try/except` 捕获 `FileNotFoundError`，没文件就空列表 |
| 字典和类混用导致大量报错 | 统一改成 `Task` 类的写法 |
| 字段名 `deadline` 和 `due_date` 对不上 | 全局统一用 `deadline` |
