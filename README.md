# 任务管理系统

一个基于控制台的 Python 待办任务管理程序，支持任务增删改查、搜索筛选、统计、数据持久化、HTML 报告导出和 OpenCV 统计图。

## 一、运行说明

1. **环境要求：** Python 3.8 及以上
2. **依赖安装：**
```

pip install opencv-python numpy

```
（仅附加任务生成统计图需要，核心功能不需要）
3. **启动方式：** PyCharm 直接运行 `main.py`，或终端输入 `python main.py`
4. **产物说明：**
- 退出时自动保存数据到 `tasks.txt`
- 导出报告生成 `report_日期.html`，双击浏览器打开
- 附加功能生成 `chart.png` 优先级统计图

## 四、数据格式

每条任务一行，字段用 `|` 分隔，存在 `tasks.txt`：

```

1 | 买牛奶 | 高 | 2026-10-10 | 未完成
2 | 写报告 | 中 | 2026-10-11 | 已完成

```

| 字段 | 说明 | 示例 |
|------|------|------|
| 编号 | 删除后自动重新编号 | 1、2、3... |
| 标题 | 不能为空 | 买牛奶 |
| 优先级 | 高 / 中 / 低 | 高 |
| 截止日期 | YYYY-MM-DD 格式 | 2026-10-10 |
| 状态 | 未完成 / 已完成 | 未完成 |

## 六、AI 使用说明

| 每次运行都要重新添加任务 | 退出时自动写入 `tasks.txt`，启动时自动读取 |
